# The Observatory // Cortex Private Vault (V12)

A fictional interactive archive website. V8 revises **the presentation of the V6 archive** so visitors see Cortex's own files, as though they have gained access to his private recovery system. The dossiers are not a player briefing or a set of missions.

## V12 — Cinematic intrusion and darker horror soundtrack

- The **repetitive Power Overload and Brute Force entry games are retired from the public login flow**. Open the emergency terminal and select **EXECUTE ARCHIVE BREACH** (or type `breach`, `hack`, `inject`, or `override`). A full-screen, roughly 9-second, automatically animated fictional intrusion shows moving hex streams, forged credentials, a security watchdog alarm, escalating decryption and a final reboot.
- The animation requires only one click, does not consume a login attempt, and can be aborted with **TERMINATE LINK** or Escape. Completing it opens the same temporary, name-only gateway as before.
- The full **five-level Trace Jammer** memory game remains accessible from the archive console; completing it still disables the five-minute session trace for that browser-tab session.
- The **cortex / element12** primary login is unchanged, as are archive dossiers, Harmony signal, simulated surveillance, and the approximately 20-second cutoff screen.
- Original browser-generated soundtrack substantially rebuilt with **deep layered drones, chromatic clashes, low heartbeats, distant metallic groans, a faster intrusion soundscape, and a lower, menacing cutoff siren**. Added a speaker-friendly 200–250 Hz overtone. Existing AUDIO ON/OFF, volume slider, and TEST MUSIC remain.
- New root-level file **breach.js** is required. Site now contains **nine** main root files: `index.html`, `styles.css`, `data.js`, `archive.js`, `audio.js`, `app.js`, `surveillance.js`, `breach.js`, `README.md`.
- These are purely theatrical local effects, not real unauthorised computer access, geolocation, facial recognition, or live camera surveillance.

## New in V11 — Harmony Radio Tower / citywide facial-correlation simulation

- **New story intercept:** A new Tiff-associated signal is logged at **Harmony Radio Tower**. The **Vinewood Sign** remains the previous signal, not the latest lead. No current position or confirmed image of Tiff has been obtained.
- The archive dashboard and **all 16 dossier views** display a cross-index strip with the newest Harmony trace.
- An **animated citywide surveillance panel** runs automatic simulated scan cycles across Harmony, Vinewood, Downtown Los Santos and Sandy Shores. Feed images, scan lines, facial targeting boxes, rolling activity messages and unverified candidate states are locally generated visual effects.
- **FORCE NEW SCAN** manually triggers another sweep and an existing sound effect. No real camera, facial recognition, location permission or external service is used.
- Cortex's private notes and linked cases now reference the Harmony intercept and expanded sweeps while keeping his knowledge limited; Delilah's memory recovery remains unknown to him.
- New file **surveillance.js** is required. Publish **nine** root-level website files (index.html, styles.css, data.js, archive.js, audio.js, app.js, surveillance.js, breach.js, README.md).

## Publish on GitHub Pages

1. Extract this ZIP.
2. Upload all **nine files** to the root of your existing `observatory-rp` GitHub repository, replacing the old versions.
3. Commit. GitHub Pages updates the published site automatically when configured to deploy from `main` / `/(root)`.
4. If you still see the previous version, hard-refresh the page or reopen it in a private browser tab to avoid cached JavaScript.

There is no build step or external dependency; the main entry point is `index.html`.

## Important hosting note

This website is a fictional game interface. GitHub Pages is public static hosting: the displayed login is not secure authentication and anyone can download the dossier data or see the credential values in JavaScript. Use only fictional or otherwise publicly shareable content. The location-found sequence is simulated and does not track the visitor.
